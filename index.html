01

Sequence

Learn how instructions are executed step by step in a specific order.

Example: Calculate the area of a rectangle

IPO (Input → Process → Output)

Input: Length, Width

Process: Calculate Area based on Length and Width

Output: Area

Pseudocode

start
read length, width
area = length * width
print area
stop

Python Code

length = float(input("Enter length: "))
width = float(input("Enter width: "))
area = length * width
print("Area:", area)
02

Selection

Learn how programs make decisions based on conditions.

Single Selection/ Dual Selection/ Multiple Selection
Example: Determine whether a student passes

IPO (Input → Process → Output)

Input: Mark

Process: Determine "Pass" or "Fail" based on Mark

Output: "Pass" or "Fail"

Pseudocode

start
read mark
if mark >= 40 
    print "Pass"
else
    print "Fail"
end if
stop

Python Code

mark = float(input("Enter mark: "))
if mark >= 40:
    print("Pass")
else:
    print("Fail")
03

Repetition

Learn how loops repeat instructions until a condition is met.

Counter Controlled
Example: Display average mark for 5 students

IPO (Input → Process → Output)

Input: mark for 5 times

Process: Repeat calculate total based on mark for 5 times
Calculate average based on total

Output: average

Pseudocode

start
i = 0
total = 0                  
while i < 5
    read mark
    total = total + mark
    i = i + 1
endwhile                  
average = total / 5
print average                   
stop

Python Code

total = 0
i = 0                    
while i < 5:
    mark = float(input("Enter mark: "))
    total = total + mark
    i = i + 1                 
average = total / 5                   
print("Average mark =", average)
04

Repetition

Learn how loops repeat instructions until a condition is met.

Sentinel Controlled
Example: Display total miles for a few days until -1 is entered

IPO (Input → Process → Output)

Input: miles for several times until -1 entered

Process: Repeat calculate total based on miles for several times until -1 entered

Output: total

Pseudocode

start
total = 0
read miles                  
while miles != -1
    total = total + miles
    read miles
endwhile                  
print total                   
stop

Python Code

total = 0
miles = float(input("Enter miles (-1 to stop): "))
while miles != -1:
    total = total + miles
    miles = float(input("Enter miles (-1 to stop): "))
print("Total miles =", total)
